# Cybersecurity

## Kali Linux Basic Commands

This repository contains a reference image with commonly used Kali Linux terminal commands. It is intended for beginners learning Linux and cybersecurity fundamentals.

![Kali Linux Basic Commands](kali%20linux%20basic%20commands.jpeg)

### Topics Covered

- Navigating directories
- Listing files and folders
- Creating, copying, moving, and deleting files
- Managing directories
- Viewing file contents
- Checking system information
- File permissions
- Network-related commands
- Installing and managing software packages

### Usage

Use the image as a quick reference while practicing commands in a Kali Linux terminal or another Debian-based Linux distribution.

> **Note:** Run commands carefully, especially those involving file deletion, permissions, networking, or administrative privileges.
